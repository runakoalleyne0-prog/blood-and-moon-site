- reader/: Blood & Moon Chapter 1 reader page

PUBLISH WITH GITHUB PAGES
1. Open the repository Settings on GitHub.
2. Select Pages from the sidebar.
3. Under Build and deployment, choose Deploy from a branch.
4. Select branch main and folder /(root), then Save.
5. Wait for GitHub Pages to publish the site. The public URL will appear in Settings > Pages.

This is a static HTML website. Pages marked Coming Soon are placeholders for future chapters and artwork.
